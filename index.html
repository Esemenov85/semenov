🎨 Лекция 1: Основы графики Базис

  • 4 вида графики: растровая, векторная, фрактальная, 3D.
  • Растр: сетка пикселей, фото, потеря качества при увеличении.
  • Вектор: математические контуры, логотипы, иконки, масштабирование без потерь.
  • Цветовые модели: RGB (экраны), CMYK (печать), HSB (тон, насыщенность, яркость).
  • Форматы: JPEG (фото), PNG (прозрачность), SVG (вектор), PSD/XCF (рабочие).
  • PPI/DPI: PPI — для изображения, DPI — для печати.
  • Растровый редактор: слои, выделение, маски, ретушь, трансформации.
  • Неразрушающее редактирование: маски вместо ластика, смарт-объекты.

📐 Лекция 2: Векторная графика Инструменты

  • Анатомия вектора: опорные точки (узлы), сегменты (прямые/кривые), контуры, заливка, обводка.
  • Кривые Безье: управляющие рычаги задают изгиб. Минимум узлов — максимум плавности.
  • Boolean-операции: объединение, вычитание, пересечение, исключение — основа создания иконок.
  • Текст как вектор: перевод в кривые (Convert to Path) для логотипов, но не для UI-макетов.
  • SVG: текстовый формат, масштабируемость, изменение цвета через CSS, лёгкий вес.
  • Редакторы: Adobe Illustrator, CorelDRAW, Inkscape, Figma.

📏 Лекция 3: Композиция и сетки Структура

  • Композиция: организация элементов, управление вниманием, визуальное единство.
  • Иерархия: главное → важные детали → дополнительная информация.
  • Контраст, нюанс, тождество: выделение, глубина, система.
  • Ритм и отступы: единая шкала (4, 8, 16, 24, 32, 48, 64).
  • Симметрия/асимметрия: покой vs динамика, но оба сохраняют баланс.
  • Композиционный центр: главное смысловое ядро экрана.
  • Модульная сетка: колонки, межколонники, поля, модули, базовые линии.
  • Типы сеток: рукописная, колоночная (12 колонок), модульная, иерархическая.
  • Правило третей и золотое сечение: ориентиры, но интерфейсы строятся на сетках.

🎨 Лекция 4: Цвет и типографика Система

  • Цветовой круг Иттена: основные, составные, третичные цвета.
  • Гармонии: монохромная, комплементарная, аналоговая, триада.
  • Психология цвета: ассоциации (красный — энергия, синий — доверие).
  • WCAG: контраст 4.5:1 для текста, 3:1 для крупного. Цвет не единственный носитель смысла.
  • Палитра интерфейса: роли (primary, secondary, success, error, surface, disabled).
  • Типографика: кегль, интерлиньяж, трекинг, кернинг, гарнитура.
  • Классификация: serif, sans-serif, моноширинные, рукописные, декоративные.
  • Шрифтовая пара и иерархия: заголовок + текст, стили в Figma.

🖼️ Лекция 5: Коррекция и ретушь Обработка

  • Тоновая коррекция: яркость, тени, света. Цветовая: баланс, насыщенность, оттенок.
  • Гистограмма: график распределения яркостей (слева тени, справа света).
  • Levels: чёрная/белая точки, средние тона. Curves: гибкая S-кривая для контраста.
  • Баланс белого: нейтральные объекты должны выглядеть нейтрально (температура, оттенок).
  • Корректирующие слои и маски: неразрушающее редактирование (белое — показываем, чёрное — скрываем).
  • Смарт-объекты: сохраняют исходное содержимое при трансформациях.
  • Ретушь: Healing Brush, Patch, Clone Stamp, частотное разложение.
  • Резкость: умеренно, оценивать при 100% масштабе.
  • Оптимизация: размер, формат, сжатие, вес файла.

🧩 Лекция 6: UI/UX и проектирование Процесс

  • UI vs UX: UX — опыт и логика, UI — визуальный интерфейс.
  • Пользовательская задача: что человек хочет сделать? Аудитория и контекст.
  • User Flow: схема последовательности экранов и действий.
  • Wireframe: структура (серые схемы). Mockup: визуал (цвета, шрифты). Prototype: интерактив.
  • Дизайн-системы: Flat, Material, HIG, Neumorphism.
  • Адаптивность: перестройка структуры, а не масштабирование.
  • Референсы и мудборд: анализ и согласование стиля до детальной работы.

⚙️ Лекция 7: Figma и прототипирование Инструмент

  • Адаптивность: перестройка под ширину экрана. Брейкпоинты: 480, 768, 992, 1200 px.
  • Mobile-first: сначала компактная версия, затем расширение.
  • Frame vs Group: Frame — контейнер, участвует в компоновке, обрезке, Auto Layout.
  • Auto Layout: автоматическое размещение, отступы (Gap, Padding), Hug/Fill/Fixed.
  • Constraints: привязка элементов при изменении размера родителя.
  • Компоненты и экземпляры: Main component → Instance, варианты состояний.
  • Стили и Design tokens: именованные значения (color-primary, space-16).
  • Прототипирование: связи, Smart Animate, Matching objects.
  • Dev Mode: передача размеров, отступов, ресурсов разработчику.

✨ Лекция 8: Анимация и передача ресурсов Финал

  • Зачем анимация: обратная связь, внимание, навигация, вовлечённость. Не должна мешать.
  • Виды: GIF, CSS, Lottie (JSON), видео. Lottie — стандарт для UI.
  • Принципы: Easing (смягчение), инерция, длительность 200–300 мс (микро) / 300–500 мс (переходы), согласованность.
  • Раскадровка: 3–5 кадров для продумывания сценария.
  • Инструменты: Figma Smart Animate, After Effects, Principle, Protopie, Rive.
  • Подготовка ресурсов: иконки SVG, изображения @1x/@2x/@3x, стили, компоненты с состояниями, Lottie/JSON, инструкция.
